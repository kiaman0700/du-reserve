# 🖥️ Du-Reserve Frontend (스마트 열람실)

이 디렉토리는 대구대학교 스마트 시설 예약 및 관리 시스템의 **프론트엔드 웹 프로젝트**입니다. 

---

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: `Next.js v16+ (App Router)`
- **Styling**: `Tailwind CSS v4`
- **Icons**: `Lucide React`
- **Language**: `TypeScript`

---

## ✨ 구현된 핵심 기능 (Implemented Features)

PRD 및 R&R 가이드라인에 맞춘 다음 프론트엔드 기능이 클라이언트 상태 기반 프로토타입으로 완벽히 구현되어 있습니다.

### 1. 학생 포털 예약 대스크 (Student Perspective)
- **실시간 좌석 현황 도면**: A구역(창가), B구역(내측)의 24개 좌석 배치 및 실시간 상태 동기화.
- **2단계 부재중 신고 시스템**: 
  - **1차 신고**: HTML5 `getUserMedia` API를 활용하여 실제 카메라 캡처를 지원합니다. 웹캠이 없을 경우, 갤러리 업로드 업로드가 차단되는 정책에 대응하기 위한 **가상 현장 스냅샷 시뮬레이터**가 활성화됩니다.
  - **30분 대기 타이머**: 1차 신고 시점부터 30분 카운트다운 타이머가 작동하여 2차 신고 연타를 차단합니다.
  - **2차 최종 신고**: 30분 경과 후 2차 사진 촬영 및 제출을 완료하면 해당 신고가 관리실 관제센터로 이관됩니다.
- **실시간 경고 팝업**: 1차 신고가 접수된 좌석의 원래 예약자가 로그인/접속 중일 경우 즉각 `⚠️ 장기 부재 경고` 모달이 노출되며, 30분 이내에 **[자리 복귀 확인]** 버튼을 통해 신고를 해제할 수 있습니다.
- **강제 퇴실 사후 알림**: 관리자가 좌석을 강제 퇴실시켰을 때, 해당 학생이 접속하면 **[🚨 좌석 강제 퇴실 처분 고지]** 및 물품 수거 장소(1층 안내 데스크) 안내 팝업이 노출됩니다.

### 2. 도서관 중앙 시설물 관제센터 (Admin Perspective)
- **실시간 접수 현황 모니터링**: 2차 증빙이 최종 완료된 좌석의 실시간 타임라인 대조.
- **이중 증거 사진 대조 (Side-by-Side Audit)**: 1차 촬영 사진과 2차 촬영 사진을 나란히 배치하여 사재기(노쇼) 행위를 시각적으로 검증합니다.
- **이원화 좌석 개방 제어**:
  1. **물품 수거 및 자리 정리**: 현장 정리 작업을 위해 클릭 즉시 좌석이 보라색(`CLEARING`)으로 변경되고 **10분 타이머**가 가동됩니다. 10분이 지나면 시스템이 자동으로 `AVAILABLE`(빈자리)로 전환합니다.
  2. **즉시 빈자리 전환**: 즉각적인 좌석 확보가 가능한 경우, 10분 유예 시간 없이 즉시 `AVAILABLE` 상태로 전환합니다.

### 3. 테스트용 시뮬레이터 (DEV MODE)
- 화면 오른쪽 하단에 **"타이머 속도 60배속 가속"** 스위치가 있습니다.
- 활성화 시, 검증 대기 30분은 **30초**로, 물품 정리 10분은 **10초**로 가속 동작하여 타이머 시나리오를 빠르게 검증할 수 있습니다.

## 🚀 로컬 개발 서버 실행 방법

1. **의존성 패키지 설치** (frontend 디렉토리 진입 확인)
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   ```bash
   npm run dev
   ```

3. 브라우저에서 `http://localhost:3000` 접속 후 사용 가능합니다.
   - 상단 내비게이션 바의 **[학생 화면]** / **[관리자 화면]** 탭을 클릭하여 각 역할을 손쉽게 오갈 수 있습니다.

## 🤝 백엔드 개발자 (팀원 B) 협업 가이드

프론트엔드 UI 컴포넌트의 모든 상태(State) 및 API 시그니처는 Supabase DB 스키마 설계에 맞춰 설계되었습니다. 
다음 사항을 연동해주시기 바랍니다:

1. **상태 관리 연동 (Supabase WebSockets / Realtime)**
   - `page.tsx` 내부의 `seats` 및 `absenceReports` 로컬 상태를 Supabase Realtime 채널 구독으로 변경하여 좌석 현황이 모든 유저에게 즉각 브로드캐스팅되도록 설정하십시오.
2. **인증 처리 (Supabase Auth)**
   - `studentUser` 및 `adminUser` 프로필 정보를 Supabase Auth 세션 정보와 동기화하고, 로그인 및 가입 폼을 연결하십시오.
3. **Storage 사진 업로드**
   - `CameraCapture.tsx`에서 캡처된 Base64 Image string을 Blob으로 변환한 뒤, Supabase Storage 버킷인 `evidence-photos`에 저장하고 public URL을 얻는 로직을 추가하십시오.
